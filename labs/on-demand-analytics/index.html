Lab / Late dependency

A dependency appears only after an action

Start Full PTK SCA before opening the review target. The initial document alone does not load the analytics dependency.

  1. Setup: open the review target and note that analytics has not loaded.
  2. One action: press Open analytics workspace.
  3. Vulnerable outcome: the same-origin jQuery 3.4.1 resource loads and the page displays ANALYTICS-DEPENDENCY-LOADED.
  4. Repaired outcome: perform the same action on the repaired target; the summary still works using jQuery 3.7.1 and displays ANALYTICS-DEPENDENCY-REVIEWED.

Reset: reload the target to return to the unloaded state; begin a fresh PTK scan for an independent component result.

Exact PTK evidence to inspect: Full 10.0.0 Firefox positive/repaired controls confirm a review-only SCA finding for the action-loaded jQuery 3.4.1; the repaired 3.7.1 route did not emit that vulnerable-version finding. Other browsers still need their own qualification.
