JWT browser and request evidence

Follow one synthetic token across the browser and HTTP request surface.

These paired cases demonstrate browser-storage discovery and exact Authorization, cookie, form and nested-JSON request carriers. The separate nested-JSON exploit case shows why a weak signing key matters. All tokens are synthetic.

Two execution modes

Static discovery, local active testing.

Storage cases work on GitHub Pages. Request mutation needs the loopback-only Node or Docker runtime so POST bodies, cookies and response behavior are deterministic.

!

Use only on authorised targets. The local APIs are deliberately vulnerable simulations and must not be exposed to an untrusted network.
